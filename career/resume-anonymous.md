## 대표 프로젝트

### Project Priest

**팀 액션 게임 · 2026.09 · 팀 발표 09.29**  
**상태:** 팀 발표 완료　**담당:** 적 AI · 무기 파츠 · UI 데이터 연동

- AIController·Behavior Tree·Blackboard를 연결해 행동 조건을 구성
- 파츠 정보의 저장·참조·장착 데이터와 UI 전달 경로 점검

**문제 해결:** Box 높이를 조정할 때 판정이 달라지는 현상을 관찰했습니다. 발표 자료에는 Notify 시점 범위 검사 방식도 정리되어 있습니다.  
**결과·범위:** 적 AI와 파츠 작업 및 2026.09.29 팀 발표 기록이 있습니다. 플레이 영상에는 전투·인벤토리·구역 이동·보스전이 담겼습니다.

### Don’t Drop

**리슨 서버 팀 대전 게임 · 2026.10.29–11.09 · 확인된 기록**  
**상태:** 개발 기록 · 완료 미확인　**담당:** 캐릭터 이동 · 입력 · 방어구 무게 연동

- FPlayerDataRow·FPlayerMovementTuningRow 설정을 CharacterMovementComponent에 적용
- 무게 변경 이벤트와 최대 속도 재계산 연결

**문제 해결:** DataTable에서 이동 값을 읽어 적용하고, 방어구 상태 변경 시 최대 속도 재계산을 연결했습니다. 11월 9일 가드 시작·종료 입력을 RequestCombatBlock(true/false)로 전달했습니다.  
**결과·범위:** 캐릭터 코드와 데이터 테이블 병합 후 빌드가 통과한 기록 및 가드 C++ 로그 확인 기록이 있습니다. 출발 속도 문제는 직접 플레이에서 관찰했습니다.

### ChatX · 숫자 야구

**개인 멀티플레이 실습 · 2026.10.02–10.12 · 학습 기록**  
**상태:** 코드 작성 · 통합 검증 미확인　**담당:** 숫자 야구 규칙 · 채팅 RPC · 상태 복제

- 1~9 중 중복 없는 세 숫자 생성·입력 검증·Strike/Ball 판정 작성
- 서버에서 Controller를 순회하며 각 소유자에게 Client RPC 전달

**문제 해결:** GameMode의 PrintChatMessageString을 통해 판정을 실행하고 Controller별 Client RPC 전달 경로를 작성했습니다. 속성 복제는 DOREPLIFETIME을 사용했습니다.  
**결과·범위:** 10월 12일 메시지 전달·숫자 야구 판정 및 복제 코드 작성과 해당 커밋 기록이 있습니다.

### 팀 TextRPG

**C++ 콘솔 RPG 팀 프로젝트 · 2026.07.29–08.05 · 작업 기록**  
**상태:** 팀 프로젝트 마무리　**담당:** 상점 구매·판매 · Item 관리 · Logger

- 상점 아이템 구매·판매 흐름 구현 및 수정
- Shop·Item 클래스 역할 분리와 unique_ptr 기반 아이템 관리

**문제 해결:** Item 클래스를 분리하고 std::unique_ptr<Item>으로 다뤘으며 판매 기능을 이어서 수정했습니다.  
**결과·범위:** 2026.08.03 리팩터링 기록과 08.05 팀 프로젝트 마무리·협업 회고가 있습니다.
