## 프로젝트

### Project Priest — Unreal Engine 5 팀 액션 게임

- 적 AI의 순찰·감지·추적·공격 흐름을 Behavior Tree와 Blackboard로 구성
- 무기 파츠 장착 및 능력치 데이터, UI 담당자와의 연동 작업
- 프레임 조건에 따른 공격 판정 누락 문제를 조사하고 수정 방향을 검토
- 상세 내용: [프로젝트 사례](projects.md)

### C++ / Unreal 개인·팀 실습

- TextRPG: 상속·다형성, 상점·아이템 관리
- FirstFPS 및 챕터 3 개인 프로젝트: Blueprint·Pawn·게임플레이 기능 실습
- ChatX: 멀티플레이 숫자 야구와 서버·클라이언트 구조 학습
- Don't Drop: 캐릭터·조작과 네트워크 구조 관련 설계·개발 기록

## 기술 문제 해결 사례

**공격 판정 누락:** 애니메이션 재생과 실제 피해 적용이 불일치하는 상황에서 충돌 판정 방식과 실행 시점을 점검했습니다. 발표 자료에는 Notify 시점 범위 검사 방식의 개선 과정이 기록되어 있습니다.

**Mesh 처리 불일치:** C++에서 조작한 Mesh와 Blueprint가 실제 표시하는 Mesh가 달라, 화면에 나타나는 컴포넌트와 처리 대상을 확인했습니다.
