# AI와 함께 개선한 개발 기록 사이트

**결과물** GitHub Pages의 개발·학습 기록 사이트 · **역할** 요구사항 정리, 화면·내용 검토, 수정 방향 결정

## 해결하려던 문제

자료가 늘면서 필요한 개념을 찾기 어려웠습니다. 문서를 전부 펼쳐 놓거나 큰 카드로 표시하면 목록이 길어졌고, 학습 일지와 다시 참고할 자료도 구분하기 어려웠습니다.

## 내가 정한 기준과 AI에 맡긴 작업

자료실은 공부했다는 소개보다 필요한 정보를 다시 찾는 공간으로 정했습니다. 관련 내용은 묶고 독립적으로 찾을 내용은 나누되, STL 종합 노트를 분량만으로 잘게 나누지 않도록 요청했습니다.

AI에는 기존 코드 조사, UI·문서 수정과 검증을 맡겼습니다. 저는 시안을 보고 글자 크기, 여백, 목록의 정보량과 탐색 방식을 조정했습니다. 모든 항목을 한꺼번에 꺼내 놓은 시안에는 정렬과 색인을 개선하는 방향으로 다시 요청했습니다.

## 검토하면서 바꾼 부분

- 자료실은 옆 분야 목록과 간결한 문서 행을 사용하고, 필요한 때 목차를 펼치도록 했습니다.
- 목차에서 한 절만 표시하던 방식은 전체 본문을 연 채 해당 위치로 이동하도록 바꿨습니다.
- 알고리즘은 제출 코드와 수정 제안을 구분하고, 미완성 기록을 통과로 바꾸지 않도록 했습니다.
- AI가 만든 코드나 팀원의 작업을 제 구현처럼 적은 내용은 바로잡았습니다.

## 결과와 범위

사이트에는 프로젝트, 학습 기록, 알고리즘, 기술 자료실이 연결되어 있습니다. 실제 사용 중 발견한 문제를 피드백하며 개선하고 있습니다.

웹 구현은 AI의 도움을 받은 작업입니다. 이 사례는 웹 코드를 모두 직접 개발했다는 경력이나, AI로 게임 전체를 완성했다는 경험으로 제시하지 않습니다. 사용성 개선 효과를 수치로 측정한 기록도 없습니다.
