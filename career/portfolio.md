# 게임 클라이언트 개발 포트폴리오

> C++ · Unreal Engine 기반 프로젝트 및 학습 기록을 정리한 공개용 포트폴리오 초안입니다. 개인 신상과 연락처는 이 문서에 포함하지 않았습니다.

## 한눈에 보기

C++과 Unreal Engine을 사용한 게임 개발을 학습하며 팀 프로젝트, 개인 실습, 문제 해결 과정을 기록하고 있습니다. 구현 여부가 확인된 작업과 설계·학습 단계의 내용을 구분하여 소개합니다.

| 분야 | 경험·학습 근거 | 수준 표기 |

| C++ | TextRPG의 상속·다형성, 상점·아이템 작업과 알고리즘 풀이 | 프로젝트·학습 기록 |
| Unreal Engine 5 | 액션 게임의 적 AI·무기 파츠, 개인 게임 실습 | 프로젝트 기록 |

## 대표 프로젝트 — Project Priest

- **형태:** Unreal Engine 5 기반 3D 액션 게임 팀 프로젝트
- **담당 기록:** 근접·원거리 적 AI, 무기 파츠 장착과 능력치 관리, UI 담당자와의 데이터 연결, 공격 판정과 사망 처리
- **기술:** C++, Unreal Engine 5, Behavior Tree, Blackboard, DataTable
- **핵심 문제 해결 사례:** 공격 모션이 실행돼도 프레임 조건에 따라 피해가 누락되는 현상을 조사하고, 발표 자료 기준으로 공격 시점의 범위 검사 방식으로 개선
- **주의:** 일부 작업 메모는 최종 코드와 다를 수 있으므로 최종 구현 여부가 불명확한 세부 사항은 확정적으로 표현하지 않습니다.

## 그 밖의 작업

| --- | --- | --- |

## 작업 방식

1. 기능의 역할과 데이터 흐름을 먼저 나눕니다.
2. 구현 중 문제가 발생하면 재현 조건과 실행 경로를 확인합니다.
3. 해결 시도와 미확인 사항을 구분하여 기록합니다.
4. 팀 작업에서는 서로 주고받을 데이터와 인터페이스를 맞춥니다.
