# 게임 개발 채용 지원 자료 점검표

> 공개용 자료를 검토하는 체크리스트입니다. 지원 회사, 채용 담당자, 계정, 연락처 등 개인·지원 정보를 저장하지 않습니다.

## 제출 문서

- [ ] 익명 기술 이력서의 기술·프로젝트 내용이 최신 기록과 일치하는가?
- [ ] 포트폴리오의 대표 프로젝트가 실제 담당 업무를 보여 주는가?
- [ ] 프로젝트별 **목표 → 담당 → 문제 → 해결 과정 → 확인 결과**가 구분되어 있는가?
- [ ] 자기소개서의 문장이 본인이 직접 설명할 수 있는 경험인가?
- [ ] 기술 면접 예상 질문에 대해 원리와 실제 사용 경험을 구분할 수 있는가?
- [ ] 공고의 필수 기술과 우대 기술을 별도로 확인했는가?

## 검증과 증빙

- [ ] 프로젝트 링크·시연 영상이 열리는가?
- [ ] 완료·시도·설계·학습 상태를 혼동하지 않았는가?
- [ ] 팀 결과물과 개인 담당 부분을 분리했는가?
- [ ] 개선율·성능 수치·테스트 성공 등 근거 없는 성과가 없는가?
- [ ] 코드 예제가 실제 프로젝트 코드인지 설명용 예제인지 표시했는가?
- [ ] 저장소의 README와 프로젝트 소개가 서로 모순되지 않는가?

## 공개 개인정보·보안 점검

- [ ] 이름·전화번호·생년월일·주소·학교·직장 등 개인 식별 정보가 없는가?
- [ ] 이메일·개인 계정·지원 내역을 문서에 실수로 적지 않았는가?
- [ ] 토큰, API 키, 비밀번호, 인증 설정, 내부 서버 주소가 없는가?
- [ ] 비공개 저장소 주소와 로컬 폴더 경로가 노출되지 않는가?
- [ ] 팀원 개인정보와 비공개 자료를 포함하지 않았는가?
- [ ] PDF/문서 변환 시 작성자 메타데이터·숨겨진 주석도 확인했는가?

## 지원 시 별도로 준비할 정보

이 공개 폴더에 보관하지 않고 채용 플랫폼의 비공개 입력란 또는 별도 비공개 문서에서 관리합니다.

- 지원자 실명 및 연락처
- 학력·경력의 공식 명칭과 기간
- 회사별 지원 동기와 채용 공고 링크
- 면접 일정, 채용 담당자 연락처, 지원 상태

**주의:** 현재 홈 화면에 별도 요청으로 추가된 공개 이메일 링크는 이 폴더의 익명 문서와 구분해 관리합니다.
