# DEV / EVIDENCE — 채용 검토형 역량 대시보드

**게임 클라이언트 개발 포트폴리오 / C++ · Unreal Engine**

> 이 브랜치는 별도로 설계한 포트폴리오 시안입니다. 공개 GitHub Pages의 `main`과 다르며, 별도 배포하지 않았습니다.

## 사이트 설계

**읽는 순서:** 보유·학습 기술 → 근거 프로젝트 → 직접 기여 → 확인 가능한 결과와 한계

숙련도 점수·사용자 수·향상률 등 임의의 수치를 넣지 않고 검증된 코드·작업 기록만 표시합니다.

| 화면 | 이동 경로 |
| --- | --- |
| 역량 개요 | `#home` |
| 근거 매트릭스 | `#review` |
| 프로젝트 검토표 | `#projects` |
| 이력서·문서 | `#career` |
| 작업 기록 | `#list` |

## 콘텐츠 구성

- **대표 기술 사례 4개:** Project Priest (AI·공격 판정), Don’t Drop (이동·입력), ChatX 숫자 야구 (게임 규칙·RPC), 팀 TextRPG (C++ 클래스 책임·소유권)
- **보조 실습 4개:** CX 차량 프로젝트, FirstFPS, 개인 TextRPG, 챕터 3 개인 프로젝트
- **공개 문서 7개:** 포트폴리오, 프로젝트 기술 사례, 익명 기술 이력서, C++, Unreal, 멀티플레이, 디버깅 기술 노트
- **기존 TIL 기능:** 학습 기록·알고리즘·자료실·원본 프로젝트 페이지를 유지

공개 포트폴리오에서 반복 기술, 면접 질문 초안, 자기소개서 원고와 체크리스트를 제외했습니다. 별도 준비용 파일은 원본 손실을 방지하기 위해 브랜치에 보존했습니다.

## 근거 및 범위

동일한 기술적 사실은 `data/portfolio-evidence.js`에서 관리하며, 기록 ID는 `data/manifest.js`와 대조합니다. 사례 화면은 브랜치 전용 `assets/site-experience.js`와 `assets/site-experience.css`로 구성합니다.

- 2026-11-09까지의 공개 작업 기록을 근거로 합니다.
- Don’t Drop의 예정 마감일은 실제 완료일로 표시하지 않습니다.
- Project Priest는 팀 발표 완료와 개별 기능의 검증 범위를 분리합니다.
- 팀 작업과 개인 담당 범위를 구분하고, 실명·학력·주소 등 신상정보는 추가하지 않았습니다.

## 로컬에서 시안 열기

GitHub Desktop에서 해당 브랜치를 선택하고 `index.html`을 브라우저로 열면 됩니다. 실제 배포 사이트에 적용하려면 별도 배포 또는 병합 과정이 필요하며, 현재 `main`은 수정하지 않았습니다.
