# TIL

C++와 Unreal을 배우면서 적은 메모와 프로젝트 기록을 모은 정적 사이트다. 작성 기준은 [AGENTS.md](AGENTS.md)를 따른다.

## 화면

- **날짜별 기록 52개**: 날짜·제목·프로젝트로 찾는다. 상단 시작일과 종료일을 고르면 그 기간과 겹치는 글이 나온다. 한쪽 날짜만 골라도 된다. 날짜 없는 메모 3개와 프로젝트 전체 작업 2개는 날짜 구분에서 따로 볼 수 있다.
- **정리 자료 16개**: 기존 자료구조 문서, Velog 개념 정리, 수업 메모다. 종류·분야·글 상태와 검색으로 찾는다. 여러 분야를 고르면 모두 해당하는 자료가 나온다.
- **알고리즘 33개**: 문제 원문, 풀이 과정과 코드, 확인된 채점 결과를 보여준다. 문제 유형·풀이 상태와 검색으로 찾는다. 확인된 LeetCode 제출은 제출 내역 링크도 제공한다. 로그인해야 열리는 제출 페이지가 있을 수 있다.

주제·활동·프로젝트 조건과 날짜 조건을 함께 사용할 수 있다. 목록으로 돌아오면 선택한 조건을 유지한다. 모바일에서는 필터와 목차를 접었다 펼칠 수 있다.

`index.html`을 브라우저에서 열어 사용할 수 있고 별도 빌드는 필요 없다. 주소의 `#record=기록ID`, `#material=자료ID`, `#algorithm=문제ID`로 상세 글을 바로 연다. 각 목록 주소는 `#list`, `#library`, `#algorithms`다.

## 글과 원본

짧은 메모는 짧게 둔다. 원본에 없는 회고나 다음 계획을 덧붙이지 않고, 실제 작업과 코드, 막힌 부분을 직접 적는다. 날짜별 글은 문장 길이에 상관없이 작성된 문단을 모두 보여준다. 질문이나 남은 문제는 필요한 글에만 둔다.

Unreal 작업 이미지 21장은 관련 글 7개에 들어 있다. Velog 이미지 주소와 원문 링크를 유지한다. 자료실의 자료구조 원문 링크는 보관 원본과 같은 내용의 공개용 HTML 사본으로 연결된다. Velog 자료는 원문으로 연결하고, 공개 주소가 없는 수업 메모는 원본 파일 이름을 표시한다.

알고리즘의 제출 코드와 채점 상태는 보존한다. 수정안이나 참고 예제가 당시 제출과 다른 경우 제목과 설명에서 구분한다. 제출이 통과했어도 배열 범위 문제나 문제 조건과 다른 부분이 남아 있으면 함께 적는다. 코드만 남은 문제에는 당시 생각이나 시행착오를 만들어 붙이지 않는다.

Git 기반 프로젝트 글의 날짜는 코드 변경일이다. 실행 근거가 없는 기능을 실행 성공으로 표시하지 않는다. 날짜 없는 프로젝트 ZIP은 날짜를 만들지 않고 프로젝트 전체 작업으로 둔다. CH3_1, CH3_2, CH3는 **챕터 3 개인 프로젝트** 필터로 묶으며 원래 단계와 저장소 링크는 유지한다. CH3_3는 포함하지 않는다.

## 파일

| 위치 | 내용 |
| --- | --- |
| `index.html` | 공통 화면과 스타일 |
| `assets/app.js` | 날짜별 글·날짜 범위·필터·상세 이동 |
| `assets/library.js` | 자료실 검색과 상세 화면 |
| `assets/algorithms.js` | 문제 검색과 풀이 화면 |
| `data/manifest.js` | 날짜별 기록 목록 |
| `data/연도/월/날짜.js` | 날짜별 본문 |
| `data/undated/`, `data/project-period/` | 날짜 없는 메모와 프로젝트 전체 기록 |
| `data/library-index.js`, `data/materials/library.js` | 자료실 목록과 본문 |
| `data/algorithms.js` | 알고리즘 풀이와 문제·제출 링크 |
| `data/guides/stl-reference.html` | 자료구조 원문 공개용 사본 |
| `local/` | Git에서 제외한 원본 사본, 작업 자료, 검증 도구 |

새 날짜별 글은 고유 `id`, `date`, `title`, `study_content`와 필요한 경우 `learning_process`, `questions`, `mistakes_or_difficulties`, `images`, `velog`, `repository`, `references`를 적는다. `window.TIL_FILES[파일경로]`에 저장하고 목록에도 같은 ID·제목·분류·파일경로를 등록한다. `summary`는 검색과 목록 데이터용이며 날짜별 카드에서는 표시하지 않는다.

`unreal-containers`는 아직 게시하지 않은 초안이다. 예제 실행 여부와 Velog 게시 여부를 구분한다. 오래된 생성·마이그레이션 도구는 현재 편집 내용을 덮어쓸 수 있으므로 다시 실행하지 않는다.

## 검증

저장소 루트에서 실행한다.

```text
node local/tools/test-navigation.cjs
node local/tools/verify-daily.cjs
node local/tools/verify-library.cjs
git diff --check
```

화면은 데스크톱과 모바일에서 긴 글, 이미지, 카드 전체의 hover·focus, 날짜 범위, 필터, 상세 이동과 외부 링크를 함께 확인한다. 커밋·푸시·병합은 사용자가 해당 작업에서 직접 요청했을 때만 실행한다.
