# TIL

## 정리된 학습 자료

왼쪽 **보기 방식 → 정리된 학습 자료**에서 날짜별 기록과 분리된 개념 중심 자료실을 엽니다. 현재 기존 자료구조 HTML에서 개념별로 나눈 정리 23개, 개념 중심으로 선별한 Velog 발췌 9개, 수업·문법 노트 2개를 포함합니다. 자료 종류와 학습 분야 필터, 제목·요약·출처 검색을 제공합니다.

분류 기준은 출처가 아니라 글의 목적입니다. 배열, Big-O, 클래스, 템플릿 같은 개념·문법·원리는 자료실에 둡니다. 문 상호작용 완성, 직업 선택 기능 구현, 파츠 구조를 고민한 과정 등은 날짜별 학습·프로젝트 경험 기록에만 둡니다. 둘이 섞인 글은 개념 부분만 발췌하고 경험은 관련 실습 링크로 연결합니다. Velog 링크가 있다는 이유만으로 자료실에 자동 추가하지 않습니다.

- `data/library-index.js`: 자료실 목록 정보
- `data/materials/library.js`: 정리 문서의 본문과 Velog 요약, 노트 재구성
- `data/guides/stl-reference.html`: 원본을 변경하지 않고 만든 공개용 사본
- `assets/library.js`: 자료실 탐색 기능

`#library`는 자료실, `#material=자료ID`는 개별 정리 페이지 주소입니다. Big-O, vector, map, 자료구조 선택 기준 등을 각각 독립된 개념으로 나눴습니다. 원문 확인 여부는 상태 문구로 구분합니다. 덜 정리된 개념 메모는 **정리 중인 노트**로 분리합니다. 원본 자료의 기술 설명을 모두 재검증한 문서는 아닙니다.

자료실은 날짜 데이터와 독립된 공개 데이터입니다. 새 자료 추가 시 목록 파일과 본문 파일의 `id`를 일치시키고 원본·출처를 기록합니다. 로컬 자료는 이름만 공개하고 실제 사용자 원본은 `local/`에 보존합니다. 원본 HTML의 공개 사본에는 자료실로 돌아오는 링크만 추가했습니다.

개인 C++ / Unreal 학습 기록을 시간순으로 보여주는 정적 페이지입니다.

## Git에 포함되는 파일

- `index.html`: GitHub Pages에서 열리는 화면
- `assets/app.js`: 필터, 날짜 파일 로딩, 글 사이 이동
- `data/manifest.js`: 제목·요약·날짜·분류·파일 경로만 있는 목록
- `data/연도/월/날짜.js`: 해당 날짜의 상세 학습 기록
- `data/undated/`: 날짜를 확인하지 못한 메모
- `README.md`, `.gitignore`

`index.html`을 브라우저에서 열면 바로 확인할 수 있습니다. 별도의 빌드나 서버는 필요하지 않습니다. 목록에는 날짜·제목·한 줄 요약만 보이며, 필요한 기록만 열어 상세 내용을 확인할 수 있습니다.

## 폴더 구조

```text
TIL/
├─ index.html           # 공개 페이지
├─ data/
│  ├─ manifest.js      # 가벼운 목록 정보
│  ├─ 2026/06/2026-06-12.js
│  ├─ 2026/09/2026-09-10_2026-09-11.js
│  └─ undated/         # 날짜 미확인 메모
├─ assets/app.js       # 탐색 기능
├─ local/               # Git에 올리지 않는 원본·작업 자료
│  ├─ source-data/
│  ├─ rules/
│  ├─ notes/
│  ├─ reference/
│  └─ archive/          # 이전 규칙 문서 백업
├─ README.md
└─ .gitignore
```

## 탐색 구조

글은 태그를 여러 개 나열하는 대신 하나의 대표 학습 주제에 연결됩니다.

- C++ 기초
- Unreal · Blueprint
- 객체지향 · 게임 구조
- 포인터 · 메모리
- STL · 자료구조
- 프로젝트 · 협업

왼쪽의 주제 탭으로 관련 글을 모아 보고, 상세 화면 하단의 **같은 주제의 다른 기록**을 눌러 연결된 글로 이동할 수 있습니다. 프로젝트 버튼은 주제 탭 안에서 특정 프로젝트의 기록만 골라볼 때 사용합니다.

## 기록 추가 방법

`data/연도/월/날짜.js`에 `window.TIL_FILES = window.TIL_FILES || {};`와 `window.TIL_FILES["data/연도/월/날짜.js"] = [기록];` 형식으로 상세 글을 저장합니다. 같은 날 여러 글은 같은 배열에 넣을 수 있습니다. 각 기록에는 다음 정보를 권장합니다.

```js
{
  id: "20260806-001",
  date: "2026-08-06",
  title: "기록 제목",
  project: "프로젝트 이름",
  phase: "직접 구현",
  tags: ["C++", "실습"],
  summary: "목록에 표시할 짧은 요약", // 선택 사항
  study_content: "무엇을 학습했는지",
  learning_process: "어떤 과정으로 학습했는지",
  application: "실제로 적용한 내용",
  understanding: "당시 이해 수준",
  velog: "https://..." // 없으면 null
}
```

`data/manifest.js`의 `window.TIL_INDEX.records`에는 같은 `id`와 `title`, `summary`, `project`, `tags`, 대표 주제 `primary_topic`, `date`, `date_end`, 표시용 `date_label`, 월 필터용 `month`(예: `2026-09`), 상세 파일 경로 `file`을 추가합니다. 대표 주제는 `cpp`, `unreal`, `oop`, `memory`, `stl`, `project` 중 하나입니다. 날짜 미확인 글은 `date: null`, `month: "undated"`로 등록합니다.

월별 필터는 주제·프로젝트 필터와 함께 사용할 수 있습니다. 글을 누르면 해당 날짜 파일만 읽고 팝업 없이 본문 화면으로 이동합니다. 왼쪽에는 해당 주제의 세부 분류, 글 목차, 같은 분류의 글이 표시됩니다. 세부 분류를 누르면 해당 목록으로 이동하고, 목차를 누르면 본문의 해당 부분으로 이동합니다. 목록으로 돌아오면 기존 필터를 유지합니다. 이전/다음 버튼은 현재 필터 목록을 따라 이동합니다. `#record=기록ID` 주소와 브라우저 뒤로/앞으로 기능을 지원합니다.

현재 기록은 48개(날짜 확인 43개, 날짜 미확인 5개), 상세 파일은 47개입니다. 연결되는 짧은 작업은 7/12–13, 9/10–11, 9/17–18처럼 기간으로 묶었습니다. Git 기반 날짜는 커밋 작성일이며 실제 학습 시작일로 단정하지 않습니다. 현재 코드와 당시 이력을 구분하고 실행 검증이 없는 내용은 완료된 기능으로 표현하지 않습니다.

원본 JSON, 설계 규칙, 날짜별 메모 및 참고용 HTML은 `local/`에 보존하고 `.gitignore`로 Git에서 제외됩니다. 공개 화면에 필요한 `data/`와 `assets/`는 Git에 포함합니다. 이전 단일 데이터는 `local/archive/til-data-before-daily.js`에서 복구할 수 있습니다. `local/tools/`의 일회성 마이그레이션 도구는 새 글 추가 시 재실행하지 않습니다. Git 커밋과 업로드는 사용자가 진행합니다.

현재 작성 기준은 `local/rules/TIL_GUIDE.md` 하나로 관리합니다. 이전 규칙·설계 문서는 `local/archive/legacy-rules.zip`에서 복구할 수 있습니다.
